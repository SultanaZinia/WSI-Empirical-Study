# Deviations from the planning document

Record every place where the implementation departs from the original plan, including cases where a named
baseline could not be verified and was replaced by a generic family representative.

| Date | Component | Plan said | What we did | Why |
|------|-----------|-----------|-------------|-----|
| 2026-10-31 | Annotations | ASAP `_2` groups are exclusions (holes) | Exclusion groups are `Exclusion` and `_2`; tumor groups are `Tumor`, `_0`, `_1`. Non-polygon annotations are skipped with a warning | The 160 CAMELYON16 XMLs on Fir use only `Tumor` and `Exclusion` (`_0/_1/_2` is CAMELYON17 naming). One `Dot` annotation exists (test_066, group `None`) |
| 2026-10-31 | Patch grid | Not specified: how much tissue a patch needs | Keep a grid cell if its tissue fraction on the thumbnail mask is > 0 (`preprocess.min_tissue_fraction: 0.0`) | Follows the TRIDENT default (`--min_tissue_proportion 0.`); edge patches matter for ITCs and micro-metastases near the capsule |
| 2026-10-31 | Lesion definition | Each contiguous annotation component is a lesion | Components closer than 75 µm are merged into one lesion (`preprocess.lesion_merge_um: 75`), as in the official CAMELYON16 `evaluate.py`. This defines `lesion_id`, LSR@K denominators and strata | Contiguous-only strata disagreed with the official `evaluation/reference.csv` on 3/49 test tumour slides (6 including ITC/micro) and 26/160 overall; with the merge the test set matches exactly and 11 training slides still differ (4 of them non-exhaustively annotated) |
| 2026-10-31 | Test strata counts | Expected ~80 negative, ~28 macro, ~18 micro, ~3 ITC | Computed: 80 negative, 22 macro, 27 micro, 0 ITC slides | Matches the official reference.csv classes. With the 75 µm merge every ITC-only slide has a merged group ≥ 0.2 mm; ITCs remain analysable at lesion level |
| 2026-10-31 | Tissue mask QC | Two-level Otsu, drop glass and adipose | Kept as specified; no extra cleanup | 99.88% of annotated tumour area lies in kept patches; 3 of 590 ITC lesions (0 micro, 0 macro) fall entirely outside the grid and are reported, not dropped. Known limitation: on near-empty slides (e.g. normal_042, normal_019) slide-edge lines and specks pass Otsu and get patches. Revisit only if selectors are seen picking them |
| 2026-10-31 | TEP@K | (1/K) Σ y_i over retained | Divide by the number retained, min(K, N) | Identical when K ≤ N; for K > N the spec formula would penalise small slides for patches that do not exist |
| 2026-10-31 | MIL training | Not specified (5-fold CV, slide labels only) | CLAM defaults from mahmoodlab/CLAM `main.py`: Adam, lr 1e-4, weight decay 1e-5, ≤ 200 epochs, dropout 0.25, cross-entropy, one bag per step; early stopping on val-fold loss (patience 20, not before epoch 50), which CLAM has but leaves off by default. Gated ABMIL uses CLAM "small" sizes (→512 → 256 attention) | Published, widely used defaults instead of tuned ones; keeps every MIL arm on the same recipe |
| 2026-10-31 | Method: SiiMIL | Top-K by salient-instance / outlier score | Verified: Su et al., "Attention2Minority" (arXiv 2301.07700; Comput. Biol. Med. 2023), code github.com/JoeSu666/SiiMIL. Score = negated mean top-k cosine similarity to a CUR-selected normal key bank. Forced K: top-K by that score instead of the paper's top 30% | Key bank rebuilt per encoder from CAMELYON16 **training** normal slides only (no test leakage). The paper's "K" (nearest keys, 150) is not our budget K |
| 2026-10-31 | Method: NRK-ABMIL | Top-K by distance from the normal-key bank | Verified: Sajjad et al., Cancers 15(13):3428, 2023 (doi 10.3390/cancers15133428), code github.com/cialab/NRKMIL. Score = mean top-5 cosine similarity to a DFI-pruned normal key bank. Forced K: the K least-normal patches instead of the paper's ~10% | Same lab and nearly the same mechanism as SiiMIL (key bank built differently); expect correlated results |
| 2026-10-31 | Method: LTS | Learned gate with threshold; replace threshold with `torch.topk(gate, K)` | Verified: Chen et al., "Learnable Token Sparsification…", arXiv 2606.08641. It already uses hard top-K at inference, so there is no threshold to replace. No public code: re-implemented from the paper, with the scorer trained by a slide-label MIL loss instead of the paper's LLM text loss | Adaptation: CAMELYON16 has slide labels, not VQA text. The paper only tests K = 32 |
| 2026-10-31 | Method: Agile Pruner | Progressive, in-encoder, layer-wise schedule ending at K | **Dropped.** The real AgilePruner (Baek et al., ICLR 2026, arXiv 2603.01236) is one-shot pre-LLM pruning for natural-image LVLMs and needs a ViT [CLS] attention map that cached patch features do not have. The plan's description matches SLICEChat instead | Not applicable to frozen WSI patch features |
| 2026-10-31 | Method: SLICEChat | Listed as token merging (with PMIL), "merge to K centroids by cosine similarity" | SLICEChat (Bozkurt et al., arXiv 2609.24894, code github.com/ali-kerem/SLICEChat) is a **progressive in-encoder pruner** inside a slide encoder (Mamba + Transformer, Hilbert-ordered region drops). It fills the progressive-pruning arm (and Layer-of-Death). Retrained with a slide-label MIL head on our UNI/CONCH features instead of its CONCH v1.5 + CLIP/LLM training; exactly K forced at the final stage | The plan mislabelled it. Adaptation: different features and supervision than the paper |
| 2026-10-31 | Method: PMIL | "SLICEChat / PMIL": merge to K centroids by cosine similarity | **PMIL = Prototypical MIL**, Yu et al., Med Image Anal 85:102748, 2023 (doi 10.1016/j.media.2023.102748), code github.com/zihou98/PMIL (GPL-3.0). It clusters training features into prototypes, keeps the top-s patches by an instance-classifier score, and classifies a histogram of their similarity to the prototypes. Forced K: s = K (native). Trained with slide labels only. Not to be confused with the topology module also called PMIL (Obeid et al., ISCAS 2025) | Evaluated on CAMELYON16 and motivated by micro-metastases. It selects K patches and encodes them against centroids, so it is classed as "selection + prototype encoding", not merging into K tokens. PTCMIL (Zhao et al., MICCAI 2025) was considered and not used |
| 2026-10-31 | Method: TC-SSA | M = K slots, soft assignment W ∈ R^{K×N} | Verified: Chen, Young, Xu, arXiv 2603.01143; official code github.com/OzzyChen97/TC-SSA (MIT). Assignment is **sparse Top-2** per patch (2 nonzeros), not dense. Slots trained with a slide-label MIL head instead of the paper's LLM loss | SDI and hard-retention metrics use the sparse W as is |
| 2026-10-31 | Strata | "Largest contiguous lesion diameter" | Max Feret diameter (greatest distance between two points of the lesion), in mm via the slide's level-0 mpp. ITC < 0.2 mm ≤ micro ≤ 2.0 mm < macro | Matches AJCC "greatest dimension"; the plan did not define the diameter |
